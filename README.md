# 頻閃軌跡分析

**開始使用：<https://prohamer.github.io/motion-analysis/>**

給國中自然課用的運動分析網頁。導入影片、打點計時器紙帶照片或重複曝光照片後，標記物體位置、設定比例尺，網頁就會算出位置、速度、加速度，並畫出圖表。

不需要安裝，打開網址就能用。影片和照片只在你自己的瀏覽器裡處理，不會上傳到任何地方。

## 這個工具在做什麼

研究運動，最重要的是知道「物體在每個時刻的位置」。

- **頻閃攝影**：在暗室中用閃光燈每隔固定時間閃一次，同一張照片上就會留下物體在不同時刻的位置。
- **打點計時器**：每隔 1/60 秒在紙帶上打一個點，點和點之間的距離就是那段時間移動的距離。

兩者的共同點是**每隔相同的時間，記錄一次位置**。這個網頁做的是同一件事：

1. 從影片中每隔幾格取一張畫面，疊在一起，變成一張「頻閃照片」。
2. 你在照片上點出物體的位置（或讓電腦自動找）。
3. 用比例尺把畫面上的距離換成真實的公分或公尺。
4. 有了「時間」和「位置」，就能算出速度和加速度，畫成圖表。

## 先試試看：內建示範

在右上角的選單選一個示範，按「載入示範」。

| 示範 | 可以學到什麼 |
|---|---|
| 拋體運動 | 水平方向等速、垂直方向等加速，測出重力加速度約 9.8 m/s² |
| 等速圓周運動 | 速率不變但方向一直改變，用圓擬合算出半徑和角速度 |
| 斜面加速直線運動 | 把 x 軸轉成沿著斜面，測出沿斜面的加速度 |
| 打點計時器紙帶（照片） | 自動偵測紙帶上的點，用點距變化判斷加速 |
| 斜拍桌面（四點透視校正） | 相機沒有正對時，用四點校正得到正確距離 |

## 操作步驟：分析影片

按「**導入影片或照片…**」選擇影片，或直接把影片拖到畫面上。

### 步驟 0：影片

- **影片 fps**：影片每秒有幾格畫面，網頁會自動偵測，請確認是否正確（常見 30 或 60）。
- **拍攝 fps**：用來計算時間。一般影片和影片 fps 相同；**慢動作影片**要填實際拍攝的格率，例如 240，不然算出來的時間會錯。

### 步驟 1：選擇分析起點

1. 用畫面下方的時間軸，或 **−1 / +1** 按鈕（電腦可用鍵盤 ← →）逐格移動。
2. 找到物體**剛開始運動**的那一格。
3. 按「**設為起點**」。

### 步驟 2：影格疊加（重複曝光）

- **每隔幾格取一張**：數字越大，點和點之間的間隔越大。物體移動快就用小一點的數字，移動慢就用大一點的。
- **疊加張數**：一共要取幾個位置，最多 60 張。
- **疊加方式**：
  - 前景疊加（建議）：自動去掉背景，只留下移動的物體。
  - 取最亮：適合暗背景、亮物體。
  - 取最暗：適合亮背景、暗物體。
  - 平均：會變成半透明的殘影。
- 按「**產生疊加影像**」。

下方會顯示每個點之間的時間間隔 Δt 和總時間。

### 步驟 3：標記物體位置

**手動標記**

1. 工具列選「**標記點**」。
2. 在疊加影像上，**依照時間順序**點擊物體的中心。
3. 點錯了可以直接拖曳那個點微調，或按「復原上一點」。
4. 想確認某一點的位置，可以切到「**單格**」，一次只看一張畫面。
5. 點下方的編號，可以選擇重新標記那一點。

標到一半不想標了？後面的點**直接不標就好**，分析只會用有標記的點。按「**只保留已標記的範圍**」可以讓疊加影像也一起縮短。

**自動追蹤**

1. 先在第 1 個位置點一下物體，當作追蹤起點（選「前景偵測」時可以省略）。
2. 選擇**追蹤方式**：
   - 外觀比對：一般情況使用。
   - 前景偵測：相機固定、背景不動時使用。
3. **追蹤影格**建議選「逐格追蹤」：會追蹤每一格畫面，曲線運動比較不會跟丟。
4. 按「**自動追蹤**」。
5. 如果中途跟丟，網頁會停下來，告訴你是哪一點。手動點好那一點，再按一次「自動追蹤」，就會接著往後追。

### 步驟 4：比例尺與座標軸

**比例尺（一定要設定，不然單位會是像素 px）**

1. 按「**畫比例尺**」。
2. 在畫面中已知長度的物體上（例如一把尺）拖出一條線。按住 Shift 可以鎖定水平或垂直。
3. 在「**長度**」輸入實際長度，並選擇單位（m、cm、mm）。
4. 想移動整條比例尺，勾選「**拖動比例尺位置**」後拖曳畫面。

**座標軸（可以不設定）**

- 沒有設定時，原點是第 1 個標記點，x 向右、y 向上。
- 按「**設座標軸**」，點一下設定原點；從原點按住拖曳，可以旋轉 x 軸。斜面運動可以讓 x 軸沿著斜面，這樣 x 就是「沿斜面走了多遠」。

**畫面標示**

可以在影像上顯示每一點的時間 t、相鄰兩點的距離 Δd、累積路徑長 s、到起點的直線距離。

### 查看結果

畫面下方的「分析結果」有數據表和九種圖表，說明請看[數據分析說明](#數據分析說明)。

- **資料來源**：「疊加取樣點」只用你標記的點；「逐格追蹤」會用每一格的追蹤資料（需要先做逐格自動追蹤）。
- **複製表格**：可以直接貼到 Excel 或 Google 試算表。
- **下載 CSV**：Excel 可以直接開啟。
- **匯出影像**（工具列）：把疊加影像連同標記存成 PNG。

## 操作步驟：分析紙帶或重複曝光照片

按「**導入影片或照片…**」選擇照片，網頁會自動切換成照片模式。

### 步驟 0：照片與時間間隔

時間間隔有兩種設定方式，按上方的切換鈕選擇：

**用頻率計算**

- **打點／閃光頻率 Hz**：
  - 打點計時器：台灣電源是 **60 Hz**，每秒打 60 個點，每點間隔 1/60 秒。
  - 重複曝光照片：填閃光燈的頻率。
- **每幾個點標一次**：打點計時器的點很密，通常每 6 點標一次，Δt = 6 ÷ 60 = 0.1 秒。重複曝光照片填 1。

**直接輸入秒數**

題目或實驗已經告訴你「每隔幾秒」時使用，例如「閃光每 0.05 秒一次」。

- **標記點的時間間隔（秒）**：相鄰兩個標記點之間的時間。也可以直接按 0.1、0.05、0.04、0.02 s 的常用按鈕。
- **自動偵測時每幾個點取一**：用「自動偵測點」時才會用到。例如紙帶上每 6 點才算一個 0.1 秒，就填 6；每個點都要用就填 1。

兩種方式下，網頁都會顯示最後使用的時間間隔 Δt。

### 步驟 3：標記點

**手動標記**：依照時間順序點擊要標記的點。選取點後，按「刪除選取點」可以刪除，後面的點會自動往前補。

**自動偵測**：

1. 按「**框選偵測範圍**」，把紙帶框起來，避免抓到尺上的刻度或文字。
2. 選擇**點的樣子**：紙帶選「亮背景上的暗點」，閃光照片選「暗背景上的亮點」。
3. 填入**點的直徑**（大約幾個像素）。
4. 按「**自動偵測點**」。網頁會找出所有的點，再依「每幾個點標一次」取點。
5. 抓到太多雜點就降低**靈敏度**，抓不到就提高。
6. 如果第 1 點的方向錯了，可以在「第 1 點在」改成左邊、右邊、上面或下面。

開頭點很密、重疊在一起的那一段，框選時排除在外就好。

### 步驟 4：比例尺

在照片中的尺上拉一條線，輸入長度。拍照時記得把尺放在紙帶旁邊。

## 進階：距離校正

相機沒有正對運動平面，或尺和物體不在同一個平面時，量出來的距離會不準。在「**步驟 5：距離校正（進階）**」勾選「啟用距離校正」，有三種方法：

| 方法 | 什麼時候用 | 怎麼做 |
|---|---|---|
| **四點透視校正**（推薦） | 斜著拍，例如從斜上方拍桌面 | 在運動平面上放一個已知尺寸的長方形（A4 紙是 29.7 × 21 cm），依序點它的左下、右下、右上、左上四個角，輸入寬和高 |
| 距離修正 | 尺和物體不在同一個平面，但都正對鏡頭 | 輸入相機到尺的距離、相機到運動平面的距離 |
| 拍攝夾角修正 | 知道相機傾斜的角度 | 輸入夾角和傾斜方向（只是近似，相機要離很遠才準） |

四點校正完成後，畫面會出現校正格線。格線貼合平面，就表示校正正確；不想看到格線時，可以勾選「隱藏透視格線與四角標示」。

為什麼推薦四點校正？斜著拍時，遠的地方看起來比近的地方小，只修正一個角度修不掉這種「近大遠小」。在「斜拍桌面」示範中：

| 方法 | 算出的加速度 | 正確值 |
|---|---|---|
| 只用尺 | 46 cm/s² | 60 cm/s² |
| 四點透視校正 | 60.2 cm/s² | 60 cm/s² |

## 數據分析說明

### 數據表每一欄的意思

| 欄位 | 意思 | 單位（以公尺為例） |
|---|---|---|
| # | 第幾個標記點 | |
| 影格 | 這一點在影片中的第幾格（照片模式是紙帶上第幾個點） | |
| t | 時間，第 1 點是 0 | s（秒） |
| x、y | 位置，以原點為準，x 向右、y 向上 | m |
| Δd | 和前一點之間的距離 | m |
| vx、vy | 水平方向、垂直方向的速度 | m/s |
| \|v\| | 速率（速度的大小，不管方向） | m/s |
| ax、ay | 水平方向、垂直方向的加速度 | m/s² |
| s | 從第 1 點開始，沿著路徑累積走了多遠 | m |

速度和加速度有正負號：正的代表往 +x（右）或 +y（上），負的代表往反方向。

### 速度怎麼算

我們只知道每一點的位置，不知道瞬間的速度，所以用**前後兩點**來估算：

> **某一點的速度 = （後一點的位置 − 前一點的位置）÷（後一點的時間 − 前一點的時間）**

例如紙帶示範的第 2 點（t = 0.1 s）：

- 前一點：t = 0 s，x = 0 cm
- 後一點：t = 0.2 s，x = 7.00 cm
- 速度 = (7.00 − 0) ÷ (0.2 − 0) = **35 cm/s**

為什麼要用前後兩點，而不是這一點和下一點？因為用前後兩點算出的平均速度，剛好最接近「中間那一刻」的速度，誤差最小。

### 加速度怎麼算

加速度是「速度改變得多快」。網頁先算出前半段和後半段的平均速度，再看速度變了多少：

> **加速度 = 速度的變化 ÷ 經過的時間**

### 為什麼第一點和最後一點顯示「—」

第一點前面沒有點，最後一點後面也沒有點，沒辦法用「前後兩點」來算，所以顯示「—」。

**「—」代表「沒有算」，不是「速度為 0」。** 如果需要第一點的速度，可以用圖表的二次擬合求初速（見下方）。

### 用點距 Δd 判斷運動（紙帶最好用）

每一點之間的時間相同，所以只要看 Δd 怎麼變化：

| Δd 的變化 | 運動情形 |
|---|---|
| 每段都一樣 | 等速度運動 |
| 每段都**多一樣的量** | 等加速度運動（越來越快） |
| 每段都**少一樣的量** | 等加速度運動（越來越慢） |
| 不規則 | 加速度在改變 |

等加速度運動可以直接用 Δd 算出加速度：

> **加速度 = （後一段 Δd − 前一段 Δd）÷ Δt²**

例如紙帶示範：Δd 依序是 2.75、4.25、5.75 cm，每段多 1.50 cm，Δt = 0.1 s：

加速度 = 1.50 ÷ 0.1² = 1.50 ÷ 0.01 = **150 cm/s²**

### 圖表怎麼看

| 運動情形 | 位置–時間圖（x–t） | 速度–時間圖（v–t） | 加速度–時間圖（a–t） |
|---|---|---|---|
| 靜止 | 水平線 | 在 0 的水平線 | 在 0 附近 |
| 等速度 | 斜直線，斜率 = 速度 | 水平線 | 在 0 附近 |
| 等加速度 | 拋物線（曲線） | 斜直線，斜率 = 加速度 | 水平線 |
| 等速圓周 | 軌跡 y–x 是圓 | 速率 \|v\| 是水平線 | 方向一直改變 |

小提醒：

- **速度–時間圖下方的面積 = 位移**。
- 水平運動看 x，鉛直運動看 y，斜向或曲線運動看速率 \|v\| 或路徑長 s。
- 每張圖可以勾選「**連線**」把點連起來，勾選「**顯示各點數值**」標出每一點的數值。滑鼠移到點上（手機點一下）也能看數值。

### 擬合是什麼

實驗數據一定有誤差，點不會剛好排成一條線。**擬合**就是找一條最貼近所有點的線或曲線，用它來代表整體的變化。R² 越接近 1，代表點越貼近這條線。

| 擬合方式 | 適合用在 | 可以得到 |
|---|---|---|
| 直線擬合 | 等速度的 x–t 圖、等加速度的 v–t 圖 | 斜率 = 速度（x–t）或加速度（v–t） |
| 二次擬合 | 等加速度的 x–t 圖或 y–t 圖 | **加速度 = 2 × 二次項係數**；一次項係數 = 初速 |
| 圓擬合 | 圓周運動的軌跡圖 | 圓心、半徑、角速度、週期、向心加速度 |

**為什麼加速度 = 2 × 二次項係數？** 等加速度運動的位置公式是 x = x₀ + v₀t + ½at²，二次項係數就是 ½a，所以乘以 2 就是加速度。

**用擬合求加速度比較準。** 逐點算出的加速度（表格中的 ax、ay）對誤差很敏感，數值常常跳來跳去；擬合是用全部的點一起算，結果穩定很多。

### 範例：測量重力加速度

1. 載入「拋體運動」示範。
2. 展開「**y – t**」圖表，擬合選「**二次擬合**」。
3. 得到 y = −4.9t² + 5.94t + …。
4. 加速度 = 2 × (−4.9) = **−9.8 m/s²**，負號代表向下，這就是重力加速度。
5. 再看「**x – t**」圖用直線擬合：斜率約 3.3 m/s，代表水平方向是等速度。

### 誤差從哪裡來

- **標記不準**：差 1、2 個像素就會影響結果。可以放大畫面再標記，或用自動追蹤。
- **比例尺**：比例尺越長越準，盡量畫滿整把尺。
- **時間**：慢動作影片的「拍攝 fps」要填對。
- **相機角度**：沒有正對運動平面，距離會被壓縮，請用距離校正。
- **鏡頭變形**：廣角鏡頭的畫面邊緣會彎曲，盡量讓物體在畫面中間運動。
- **動態模糊**：物體太快會拉成一條線，可以在光線充足的地方拍，或用慢動作模式。
- **「逐格追蹤」的資料**：點數多，曲線很細緻，但相鄰兩格太近，算出的速度、加速度雜訊比較大，建議搭配擬合使用。

## 拍攝與實驗建議

- 相機用**腳架**固定，拍攝時不要移動。
- 相機盡量**正對**運動平面。
- 畫面中放一把**尺**或已知長度的物體，而且要和物體在**同一個平面**。
- 物體和背景的**顏色差異越大**越好，例如白牆前的深色球。
- 光線充足，減少動態模糊。
- 想拍快速運動，可以用手機的**慢動作模式**（記得填拍攝 fps）。

### 課堂活動點子

| 活動 | 怎麼做 | 看什麼 |
|---|---|---|
| 測量重力加速度 | 拍球自由落下 | y–t 二次擬合，加速度約 −9.8 m/s² |
| 斜面上的小車 | 拍小車從斜面滑下，旋轉 x 軸沿斜面 | 改變斜面角度，比較加速度的變化 |
| 等速與加速 | 打點計時器拉紙帶，一次等速、一次加速 | 比較兩條紙帶的 Δd |
| 拋體運動 | 拍水平拋出的球 | 水平等速、垂直等加速 |

## 瀏覽器與手機

建議使用最新版 Chrome、Edge 或 Safari；Firefox 也可以使用。

手機和平板也能用：

- 雙指可以縮放、移動畫面。
- 點一下標記點，會顯示該點的時間、位置和速率。
- 拖曳點的時候，角落會出現放大鏡，手指不會擋住要對準的位置。
- 下方有「畫面／設定／結果」快速跳轉列。
- 為了避免記憶體不足，手機上的分析解析度會降到最寬 960 px。

**影片格式**：建議 MP4（H.264）。iPhone 用 Safari 可以直接開 iPhone 拍的影片；但電腦上的 Chrome 有時打不開 iPhone 的影片（HEVC 格式），請先轉檔，或把 iPhone 的「設定 → 相機 → 格式」改成「最相容」。

頁面字型從 Google Fonts 載入；如果學校網路擋住，會自動改用系統字型，功能不受影響。

## 給老師：用 GitHub Pages 發布

1. 在 GitHub 建立新的儲存庫 `motion-analysis`，設為 Public。
2. 按 **Add file → Upload files**，上傳 `index.html` 和 `README.md`，再按 **Commit changes**。
3. 開啟 **Settings → Pages**。
4. **Source** 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
5. 等一到兩分鐘，網址就是 <https://prohamer.github.io/motion-analysis/>。

之後要更新，只要再上傳新的 `index.html` 覆蓋舊檔即可。網頁標題旁的「?」會連到這份說明；如果儲存庫改了名稱，要一起修改 `index.html` 裡的連結。
